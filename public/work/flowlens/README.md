# Flowlens — case study media

`dashboard.svg` is a placeholder standing in for a product screenshot of the Flowlens
observability UI. Replace it with a real capture (PNG or JPEG, 16:9, at least 1600×900) and update
`media.src` in the `flowlens` entry of `lib/content/projects.ts`.

Removing `media` entirely — or setting `{ kind: "none" }` — falls back to the striped
`mediaPlaceholder` block.
